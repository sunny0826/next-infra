**日期：** 2026-08-04  
**状态：** `REVIEW`  
**范围：** Bridge 侧纯文件合同与路径验证；不调用 codesign、`/usr/bin/open` 或 Local RPC wait。

## 交付结果

- 新增 Bridge library/availability boundary，binary entrypoint 尚未接入 auto-launch。
- `IntegrationPaths::from_home` 唯一生成 state、integration、release、run、stable App/Bridge 路径，不接受 MCP/argv 提供路径。
- `user_quit` marker 缺失时返回 clear；任何已存在 marker（包括合法 true、false、损坏、unknown、wrong mode、symlink 或 unreadable）均 fail closed 为 suppressed。
- `IntegrationRecord` 精确覆盖 DEC-G1-03 字段并使用 `deny_unknown_fields`。
- record schema/protocol/minor window、stable paths、bundle/requirements/timestamps、Team auto-launch 条件均严格验证。
- Host supported 与 Bridge required capability 必须按冻结顺序精确等于七个 Local RPC capability；重复、未知、乱序或缺失均拒绝。
- integration/mcp/releases/release/state/run 目录要求 euid-owned real `0700`；record 要求 euid-owned regular `0600`。
- `current` 只能是 euid-owned relative symlink，精确指向 `releases/<release_id>`。
- stable Bridge 必须是 euid-owned executable regular file、group/other 不可写，解析后必须等于传入的当前运行 artifact。
- stable App 与 `~/Applications` 必须是当前 euid 拥有且不可为 symlink。
