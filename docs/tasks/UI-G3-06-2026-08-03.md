# UI-G3-06 Connectors 与 Settings 验收记录

**日期：** 2026-08-03  
**结论：** `REVIEW`

Connectors：

- Connection Health 与 Resource Health 保持分离。
- last success/attempt、recent run、next schedule 与 Coverage 分列。
- supported/partial/unsupported 均有文字和 reason。
- Manual Sync 返回 SyncRun ID，并明确不等于 UI refresh。
- disabled connection 不可触发 Manual Sync。

Settings：

- start-at-login、MCP auto-launch、`user_quit` 是三个独立状态。
- unsupported capability 显式禁用并说明原因。
- data budget 与 retention 仅修改本地配置。
- Secret 与 SecretRef 不进入 DOM。
