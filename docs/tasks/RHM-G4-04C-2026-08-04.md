## 交付结果

- Bridge binary entrypoint 已接入 `ensure_host`，使用固定 HOME-derived paths、当前 executable、真实 Local RPC connector、production codesign verifier、cross-process launch coordinator、固定 launcher 和 monotonic clock。
- 缺 HOME、缺 Host 或 `user_quit` 时 child process 只向 stderr 返回安全 `host_unavailable`，stdout 保持纯 MCP JSON，并且不会在缺失安装状态时创建 `Library` 或 launch lock。
- 新增 `next-infra-host-integration` crate，Bridge 与 Desktop 共用唯一的 IntegrationPaths、IntegrationRecord、capability/protocol 校验、marker inspect/persist/clear 与 Host/Bridge artifact path contract，不再复制安全语义。
- 数据根目录固定为 `~/Library/Application Support/Next Infra`，由当前 euid 拥有并收紧为 `0700`；marker 通过同目录临时文件、`0600`、fsync 和原子 rename 持久化。
- Desktop 只接受两个固定后台参数元组：`--background --launch-source=mcp` 与 `--background --launch-source=login`。带 privileged launch 参数的其它组合全部拒绝。
- MCP launch 在 Tauri Builder 和 Runtime 之前再次检查 marker、strict integration record、`allow_mcp_auto_launch` 与当前运行的 stable App bundle；MCP 永不清除 marker。
- interactive/login launch 可清除合法 owner-only marker；symlink、wrong mode、wrong owner 或清除失败全部 fail closed。
- Tauri config 不再静态创建 WebView。interactive 按需创建主窗口；login/MCP 只启动后台 Runtime、tray 与 Local RPC，恢复操作才创建/显示 WebView。
- Desktop 成为唯一 Local RPC listener owner：run directory `0700`、lock/socket `0600`，accepted stream 恢复 blocking mode后进入 frozen session/query adapter。
- Host stop 会先停止 accept、shutdown 所有 active Bridge streams，再停止 Runtime；当前 Bridge 后续 query 明确失败，socket 由 owner listener 清理。
- `mcp-launch-v1.lock` 使用 O_NOFOLLOW + owner/mode validation + nonblocking `flock`。跨进程 child test 证明只有一个 Bridge 是 launcher leader，其余 Bridge 只等待同一 Host handshake，不重复 codesign/open。
- Local RPC handshake 与 query 使用 `poll(2)` deadline wrapper；不会修改并污染底层 Unix socket timeout，withholding handshake/query 均有界失败。
