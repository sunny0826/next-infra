## Live smoke 暴露并修复的连接器缺陷（7 项）

1. **AccessKeyId 硬编码 `"fixture-access"`**（生产代码未读 config）→ 改为从 `config.access_key_id` 读取，缺失返回 InvalidDomainValue。
2. **RegionId 带 `aliyun:` 前缀**（scope 按 `aliyun:{region}` 约定但未剥离）→ 剥离前缀后使用。
3. **所有模块共用 `ecs.aliyuncs.com`** → 按阿里云官方产品 endpoint 分派：ecs（compute.ecs / security_group / public_ip）、vpc（network.vpc / vswitch）、slb（edge.slb）、dns（edge.dns）。
4. **响应信封假设扁平 `Items`** → 真实响应是嵌套包装（`Instances.Instance`、`Vpcs.Vpc`…）→ 通用提取（`Items` 或首个对象内首个数组）。
5. **VPC 分页 PageSize=100 被拒** → 每模块页大小（VPC 系 50）。
6. **DNS 记录需要 `DomainName` 参数** → 两步走：`DescribeDomains`（上限 20）→ 逐域名 `DescribeDomainRecords`（`with_extra_params`）；域名分页按 TotalCount/空页停止。
7. **ID 字段名不统一**（`InstanceId`/`VpcId`/`VSwitchId`/`SecurityGroupId`/`LoadBalancerId`/`RecordId`/`AllocationId`，且部分响应同时含 `id`）→ 自定义 `Deserialize` 按优先级取第一个存在的 ID 字段；`parent_id` 亦从 `VpcId` 派生。
