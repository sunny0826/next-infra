# CON-G5-07 GitHub 连接器裁剪为 actions 维度验收记录

**日期：** 2026-08-07
**状态：** `DONE / ARCHIVED`
**决策（用户确认）：** 只保留 repository → workflow → workflow_run 三段纵切；移除 environments / deployments / jobs；workflow_run 属性裁剪为身份 + 成功/失败状态；改造后用户删除旧连接本地数据并重新同步。

## 变更内容

| 层 | 变更 |
| --- | --- |
| `connector.rs` | `collect_repository_children` 移除 environments、deployments 抓取与 jobs 循环；只保留 workflows(2页) → runs(1页) |
| `descriptor.rs` | 声明模块收敛为 github.repositories / github.actions.workflows / github.actions.runs；kind 收敛为 repository/workflow/workflow_run；关系收敛为 contains(repo→workflow) + executes(workflow→run)；最小权限声明收敛为 Metadata/Actions read |
| `environment/`、`deployment/` 模块 | **整个目录删除**（mapper + DTO + 上限常量 + 测试） |
| `actions/mapper.rs` | 删除 `map_jobs`/`JobDto`；`WorkflowRunDto` 与 `map_runs` 属性裁剪为 run_id / workflow_id / run_number / status / conclusion / created_at（display_title 仍作显示名；health 仍由 status/conclusion 推导） |
| `actions/mod.rs` | 删除 `MAX_JOBS_PER_RUN` / `MAX_JOBS_PER_REPOSITORY` |
| `tests/repository_contract.rs` | **整个文件删除**（仅测 environments/deployments） |
| `tests/actions_contract.rs` | 移除 workflow_job schema/relation；资源 3→2、关系 3→2 |
| `tests/connector_pipeline.rs` | replay 收敛为 3 个端点；资源 6→3、关系 5→2 |
| `composition/mod.rs` | `github_normalizer` 收敛为 3 schema + 2 关系；workflow_run allowed attributes 与 mapper 一致 |
| 前端 fixture/验收 | query-fixtures、github-goal5-adapter、GitHubGoal5.test、ConnectorsPage.test、query-fixtures.test 全部收敛到 3 资源/2 关系/3 模块 coverage |
