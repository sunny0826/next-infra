## 目标

验证固定 OpenSSH argv + probe registry + Host Key 校验对用户授权的真实 SSH alias 的端到端行为：
Host Key mismatch 拒绝、超时语义、macOS launchd / Linux systemd probe 摘要；连接失败不伪造资源状态。

---

## 验收入口

```sh
# 仅验证缺少 env 时输出 usage 并以 exit 1 失败（不联网）：
rtk cargo run --example live_smoke -p next-infra-connector-ssh --locked

# 真实 alias smoke（需要用户提供 alias）：
NEXT_INFRA_SSH_ALIAS=<alias> \
  rtk cargo run --example live_smoke -p next-infra-connector-ssh --locked

# 带 service probe（激活 launchd/systemd）：
NEXT_INFRA_SSH_ALIAS=<alias> \
NEXT_INFRA_SSH_ALLOWED_SERVICES=my.service \
  rtk cargo run --example live_smoke -p next-infra-connector-ssh --locked
```

---

## Env 契约

| 变量 | 必填 | 格式 | 说明 |
|---|---|---|---|
| `NEXT_INFRA_SSH_ALIAS` | **是** | 非空字符串，符合 `HostAlias` 校验（1-128 字符，ascii-alphanumeric + `. - _`，无 shell 元字符） | 必须在 `~/.ssh/config` 中定义，**不得**传入原始 host/IP/端口 |
| `NEXT_INFRA_SSH_ALLOWED_SERVICES` | 否 | 逗号分隔的 service ID，例 `app.service,nginx.service` | 存在时激活对应平台的 launchd（macOS）或 systemd（Linux）probe |

---

## 执行步骤（用户侧）

### 前置条件

1. **确认 alias 存在**：`grep -A3 "^Host <alias>" ~/.ssh/config` 输出非空
2. **确认免密登录**：`ssh -G <alias> > /dev/null 2>&1 && echo ok` 返回 `ok`
   - 若需要 passphrase/key，SSH Agent 必须已加载密钥（`ssh-add -l` 非空）
3. **确认非 root**：probe 以运行 `ssh` 的当前用户执行，不支持 sudo 自动提升

### 步骤

```sh
# 1. 确认可用 alias（以你的真实 alias 替换 my-mac-mini）：
ssh -G my-mac-mini | head -1

# 2. 运行 smoke：
NEXT_INFRA_SSH_ALIAS=my-mac-mini \
  rtk cargo run --example live_smoke -p next-infra-connector-ssh --locked

# 3. 检查输出：
#    - 出现 "=== LIVE-SMOKE SAFE SUMMARY ===" 区块
#    - alias 字段显示 [REDACTED]（不打印真实 alias）
#    - 无任何 host/IP/密钥/指纹内容
```

## 验收清单

### 行为验收

- [ ] **缺失 env**：不联网，直接打印 usage 说明 + exit 1
- [ ] **Host Key mismatch**：OpenSSH 报告 `REMOTE HOST IDENTIFICATION HAS CHANGED` / `Host key verification failed` → exit 2（fatal），不执行 probe
- [ ] **Auth failure**：SSH 报告 `Permission denied` / `Authentication failed` → exit 2（fatal）
- [ ] **Timeout**：在 `connect_timeout_secs=10` 内无法连接 → exit 1（validation failure），不伪造资源
- [ ] **Success**：validate ok + sync ok → exit 0，输出 safe summary

### Safe summary 内容验收

- [ ] `alias: [REDACTED]`（不打印真实 alias 值）
- [ ] `host_identity_external_id` 存在（UUID 格式，不含 host 信息）
- [ ] `probes_executed` 数字存在
- [ ] `outcome_class=success count=N` / `outcome_class=failure count=M` 存在
- [ ] `elapsed_ms` 数字存在
- [ ] `coverage` 行存在（`AuthoritativeFull` 或 `Partial`）
- [ ] 无以下内容（出现即 FAIL）：
  - 真实 hostname / IP 地址
  - `~/.ssh/config` 内容
  - `known_hosts` 指纹
  - 任何 SSH 私钥/公钥内容
  - probe stdout/stderr 原文
  - SSH 连接失败时的完整错误消息（仅显示 code + 简短 message）

### 安全边界验收

- [ ] `StrictHostKeyChecking=yes` 在 argv 中固定，不可绕过
- [ ] `UpdateHostKeys=no` 在 argv 中固定
- [ ] `BatchMode=yes` 在 argv 中固定
- [ ] `UserKnownHostsFile` / `StrictHostKeyChecking=no|accept-new` **从未出现**
- [ ] 任意命令执行：**从未发生**（只执行固定 probe registry 中的 6 条命令）

## 预期摘要格式（成功时）

```
=== LIVE-SMOKE SAFE SUMMARY ===
alias: [REDACTED]
host_identity_external_id: ssh-host:v1:<uuid>
probes_executed: 5
  outcome_class=success count=4
  outcome_class=failure count=1
elapsed_ms: 1842
coverage: AuthoritativeFull  scope=live-smoke
warnings: 1
  warning code=PartialPagination message=SSH module macos.launchd_services.v1 is partial
=== END SAFE SUMMARY ===

[live-smoke] DONE alias=<redacted> exit=0
```

## 预期摘要格式（Host Key mismatch 时）

```
[live-smoke] FATAL alias=<redacted> code=HostKeyMismatch message=SSH host key verification failed
# exit 2 — 无 probe 输出，无 safe summary
```

## 依赖

## 已知限制

- `host_identity` 每次运行生成新 UUID（仅用于此次 run 的 external_id，不持久化）；alias → host_identity 不是 1:1 映射
- macOS 和 Linux probe 在同一次 run 中只执行对应平台的 service probe（由 `uname -s` 响应决定）
- 不支持 Windows（ssh.host 只支持 macOS + Linux）
