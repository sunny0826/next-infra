## 2. Viewport 结果

| Viewport | Shell 合同 | Overflow 证据 | Inspector |
| --- | --- | --- | --- |
| 1600×1000 | Grid `188px / 1096px / 316px` | HTML/body `1600 / 1600` | 默认打开、inline 第三栏 |
| 900×800 | Grid `188px / 712px`，Context status 隐藏 | HTML/body `900 / 900` | 默认关闭；打开后 fixed rect `584,52 → 900,771` |
| 390×844 | Grid `56px / 334px`；Context 单列 `314px` | HTML/body `390 / 390` | 默认关闭；打开后 fixed rect `56,52 → 390,815` |

390px 下的宽内容保持内部滚动：

- Inventory frame：`scrollWidth 670 / clientWidth 261`。
- Connectors frame：`660 / 261`。
- Topology canvas：`760 / 261`；Primary canvas 自身为 `319 / 319`。
- Attention Queue 与 Observation Strip 在各自 frame 内出现横向 scrollbar，页面本身不横向移动。

## 3. 页面核实

- Overview：Attention Queue、Observation Strip、Critical Paths、Recent Changes 在三个 viewport 可读。
- Inventory：窄屏 table 只在 `.inventory-frame` 内滚动；row 保持键盘 selection。
- Resource Detail：Search → Inventory Detail → Resource Inspector 路径通过。
- Topology：Search 选择建立 bounded focus；390px canvas 内部滚动，legend、Frontier 与 node/edge Inspector 可达。
- Connectors：table 内部滚动；DOM 不包含 `SecretRef`；Manual Sync/coverage 语义未被 Shell 合并。
- Settings：MCP auto-launch 显示 `Unavailable` disabled control；Settings 默认关闭 Inspector。
- Timeline：始终显示 `Timeline unavailable until Goal 7`，不是 empty result。

## 4. Keyboard、Focus 与 Motion

- 真实浏览器 `Meta+K` 将 active element 设为 `#shell-search-input` combobox。
- Search focus 由父级 `.shell-search:focus-within` 提供 `2px solid rgb(79, 199, 220)`、`-2px` offset。
- `Escape` 清空搜索、关闭 listbox 并移除输入焦点；自动化回归通过。
- Inventory row 的 `Space` 进入 Resource Detail 并打开 Inspector；自动化回归通过。
- Navigation 保留 accessible name 与唯一 `aria-current="page"`。
- reduced-motion 下 HTML/body `scroll-behavior: auto`，Settings switch transition 为 `0.00001s`。
- Topology arrow-key adjacency 仍按设计明确留到 Goal 7；本任务不伪装完成。
