## 交付结果

- Topology 和 Resource Inspector 可以打开 RelationBuilder，使用冻结词汇创建跨 Connection configured Binding。
- 保存后显示明确状态提示；未聚焦的 Topology 会以新关系 source 为焦点立即渲染，表单不完整时显示可见错误而非静默禁用保存。
- configured relation 支持 update/disable，并在 mutation 后触发权威 re-query；provider/inferred relation 保持只读。
- unresolved endpoint 保留 configured evidence，并在 Topology 显示明确 placeholder。
- Supabase Self-hosted 同步投影一个 `supabase.self_hosted.instance`，通过 `supabase.contains` 连接已发现 table。
- Supabase Self-hosted instance 的稳定 identity 继续使用 scope 的不透明摘要；可选非敏感配置名用于展示，既有 schema v1 `{base_url}` 配置保持有效并回退到稳定 Provider 标签，不显示技术 scope、URL、主机、IP 或 Secret。
- Binding create/update 均拒绝相同 endpoint/kind 的 active 或 unresolved 重复；update 排除自身，disabled Binding 不阻止重新创建。
- 重复关系与非单调 mutation 时间使用不同错误分类；只有真正的重复关系会触发 UI“显示现有拓扑”，时间冲突保持弹窗并提示刷新。
- Tauri create/update 命令边界只接受冻结的六种 relation kind；UI fixture 的 update 去重与 disabled 状态语义和 Rust 服务一致。
- mutation 后 Shell 清理旧关系选择；disabled Binding 的 tombstoned relation 不进入活动 Topology，重新创建不会与历史边重叠。
- Topology 使用“上游来源 → 当前焦点 → 下游目标”的确定性走廊布局，支持曲线连边、平行关系错位、关系/端点联动高亮和画布内图例/Frontier。
- 未修改 Core、SQLite migration、Query DTO、生成 TypeScript、Local RPC/MCP；Tauri composition 仅修正既有 Binding 命令的错误分类，未新增命令。
