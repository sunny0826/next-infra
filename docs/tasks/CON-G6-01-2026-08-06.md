## 1. 交付

新增独立 `next-infra-connector-ssh` crate，交付：

- `SshConnectionConfigV1`、opaque UUID v4 `HostIdentity`、严格 alias/service allowlist validation 和稳定 `ssh-host:v1:<host_identity>` external ID。
- 六个最终 v1 `ProbeId`、固定 remote command、platform/schema/timeout/output/parser-owner metadata；公开 metadata 不暴露 command。
- 生产 `/usr/bin/ssh` executor：固定 argv、null stdin、有界 stdout/stderr、显式 child cancellation、timeout/overflow 精确 kill + reap。
- `BatchMode=yes`、`StrictHostKeyChecking=yes`，并固定关闭 forwarding、LocalCommand、ControlMaster、Agent/X11 forwarding、known-host 自动更新和自动加入 Agent。
- 按 `host_identity` 的进程级锁：相同 Connection 跨 client 串行，不同 Connection 可并发；单 batch 最多六 probes、90 秒、2 MiB。
- Host Key、认证、网络、timeout、overflow、remote failure 和 cancel 的结构化清洗分类。
- `ssh` Descriptor；全部 mapper module 保持 `Partial`，没有空 batch 或虚假 Supported。

本任务没有实现 `ReadConnector::sync`、Resource mapper、Runtime registry、UI 或 MCP，也没有连接真实 SSH host。

## 2. 安全边界

- 公开执行 API 只接受 `ProbeId`，不存在 command、argv、shell、path 或 hostname/IP setter。
- alias 与 remote command 是两个独立 argv；alias 必须先通过固定字符集校验，不能以 `-` 开头。
- child 固定 `LC_ALL=C`、`LANG=C`、`SSH_ASKPASS_REQUIRE=never`，移除 `SSH_ASKPASS`；保留当前用户 `HOME` 与 `SSH_AUTH_SOCK` 供系统 OpenSSH 使用已有配置。
- Host Key mismatch 是非 retryable fatal；不会提交此前 probe、自动接受/更新 known_hosts、旋转 identity 或把旧 Host 写成 unhealthy。
- stderr 只在 32 KiB 内用于固定 signature 分类，随后丢弃；任何公开 error/Debug 不包含 alias、地址、用户名、路径、fingerprint 或 output sentinel。
- UUID 仅作为本地随机 opaque identity，不从 alias、地址、机器信息或 Host Key 派生。

## 3. Luna Review 处理

独立 `luna_worker` Review 发现：身份状态未同步、UUID 依赖未冻结、锁粒度过宽、取消被当作 in-band failure、剩余时间语义、service allowlist 语义、Descriptor gap 和 pipe 异常未 reap。

最终处理：

- `DEC-G6-01`、决策索引与任务索引统一为 Accepted/DONE；task 为 FROZEN/IMPLEMENTED/REVIEW。
- 冻结 `uuid = 1.24.0` v4 依赖；无 serde feature，identity 使用显式 canonical 字符串序列化。
- 全局单锁改为按 `host_identity` 的弱引用锁 registry；测试证明 same identity 最大并发 1、different identity 最大并发 2。
- 预取消和执行中取消均返回顶层 `Cancelled`，不启动后续 child。
- 90 秒剩余时间显式收紧当前 probe timeout；零剩余时间才不 spawn。输出预算在 spawn 前按最大值预留。
- service IDs 明确是用户显式 remote label allowlist，由后续 parser 本地筛选，不是全局固定 catalog，也不进入 command。
- Descriptor known gaps 补齐 env/history/files/secrets/logs 与 non-root 规则。
- stdout/stderr pipe 获取异常、timeout、cancel 和 overflow 全部终止并 reap 精确 child。

## 4. 自动化证据

SSH crate 共 16 tests（3 suites），覆盖：

- UUID v4/canonical/external ID、alias injection、unknown config、service ID 数量/重复和 redaction。
- 六 Probe registry 最终 command、metadata 隐藏、schema/platform/timeout/output 上限。
- 完整 argv 顺序与固定 executable；Host Key/auth/network/unknown failure 分类。
- partial probe failure 与 Host Key fatal；空/重复/超量 batch；预取消和中途取消。
- stdout 与 stderr 分别超限、wall timeout、精确 child cleanup。
- 相同 connection 跨 client 串行、不同 connection 并发。
- Descriptor 与公共 conformance；公开 API 无 command 泄露。
