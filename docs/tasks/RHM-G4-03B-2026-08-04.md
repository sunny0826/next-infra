# RHM-G4-03B Bridge STDIO Composition 验收记录

**日期：** 2026-08-04  
**状态：** `REVIEW`  
**范围：** 独立 `next-infra-mcp` binary、固定本地 endpoint、真实 MCP STDIO child process；不包含 Host auto-launch、安装记录、Agent 用户配置或签名。

## 交付结果

- Bridge 使用 Tokio current-thread runtime，只启动 MCP STDIO transport；没有 HTTP/SSE/TCP listener。
- endpoint 固定解析为当前用户 `~/Library/Application Support/Next Infra/run`；Bridge 使用 read-only `TransportPaths::existing`，缺失目录时不创建任何 filesystem state。
- `LocalRpcMcpClient::connect_run_dir` 完成 owner/mode/socket/peer UID、Local RPC handshake 和 bridge caller composition。
- stdout 完全交给 `rmcp` JSON-RPC transport；安全失败只写 stderr 并返回非零 exit。
- Bridge normal dependency 仍只有 `next-infra-mcp`；Local RPC 只作为 child smoke 的 test dependency，不进入 production direct dependency surface。
- 新增 Local RPC client-only existing-path test，证明缺失 run directory 不会被 Bridge 创建。

## 真实 child-process smoke

测试将子进程 `HOME` 定向到短路径临时目录，启动真实 `next-infra-mcp` executable，并由真实 owner-only UDS fake Host 服务：

1. MCP `initialize` 成功，仅声明 tools/resources。
2. `tools/list` 精确七项，全部 schema/annotations 正确。
3. `tools/call get_health_summary` 返回 text + structuredContent 与 `observed_at`。
4. `resources/list` 精确两项。
5. `resources/read next-infra://health-summary/v1` 复用 Local RPC health query。
6. Query failure 返回 `isError=true` tool result，且不泄露用户路径或 SQL。
7. child 正常 EOF/exit，stderr 为空；所有 stdout 非空行均能解析为 MCP JSON。

Child smoke 连续执行 20 次通过。
