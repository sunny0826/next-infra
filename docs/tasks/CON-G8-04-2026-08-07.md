## Live smoke 暴露并修复的连接器问题

1. **DTO 与真实 API 形状不符**：`ZoneDto.account_id`（实为嵌套 `account:{id,name}`）、`DnsRecordDto.record_type`（真实字段 `type`）、`TunnelDto`/`WorkerDto.account_id`（响应体无此字段，改由请求上下文注入）→ 已修复并有真实形状测试。
2. **子模块 403 被当作硬错误**：`zones/{id}/dns_records` 403 会中止整个同步 → 新增 child-module partial 语义（镜像 GitHub 连接器）：根模块（accounts/zones）失败仍 fatal；子模块（dns_records/tunnels/workers）失败 → warning + Partial 继续；401/凭据缺失仍 fatal。新增 4 个测试（子模块 403/429/404 partial、根模块 401 fatal）。
