## 1. 交付

在 `next-infra-connector-github` 中新增三个独立模块：

- `repository`：Repository DTO、resource mapper、2,000 条上限、transient route context、Targeted exact lookup。
- `environment`：Environment/branch-policy DTO、resource/relation mapper、100 条/repository 上限。
- `deployment`：Deployment summary DTO、resource/relation mapper、200 条/repository 上限。

三类资源使用 GitHub numeric ID 构造 external ID，不受 rename、owner/name route 或输入顺序影响。输出统一稳定排序并携带 module complete/partial/bounded/failure 状态，不直接创建 `SyncOutcome`。

## 2. 安全边界

- Repository owner/name 只存在于当前调用栈的 `RepositoryRouteContext`，类型不实现 Serialize，Debug 显示 `[REDACTED]`。
- Targeted lookup 只精确匹配已有 route context；缺失时返回 `InvalidResponse`，不从 external ID 或 display name 猜 owner/repo。
- DTO 未定义 permissions、URLs、clone/SSH URL、reviewer/team/user、payload、creator、SHA/ref 或 Deployment Status。
- visibility 只接受 public/private/internal；String 限制 1,024 bytes，control/private-key/Bearer sentinel 拒绝。
- Deployment health 固定 Unknown，不根据 flags/environment 推断状态；Status endpoint 保持 known gap。

## 3. Identity、schema 与 relations

- `github-repository:{id}`、`github-environment:{id}`、`github-deployment:{id}`。
- Repository → Environment 与 Repository → Deployment 均为 `github.contains`。
- evidence 分别为 `github-provider-environment:{id}`、`github-provider-deployment:{id}`。
- field path 固定 `attributes.repository_id`；不以 environment name 推导 Deployment → Environment。
- optional default branch/environment/policy 缺失写 JSON null。
