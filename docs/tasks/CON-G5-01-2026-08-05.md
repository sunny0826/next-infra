## 1. 交付结果

新增 `next-infra-connector-github` crate，作为 `CON-G5-02` Repository/Environment/Deployment 与 `CON-G5-03` Workflow/Run/Job mapper 的共享只读基础。本任务没有实现 mapper、`ReadConnector::sync`、Runtime registry、UI 或 MCP surface，因此不会用空 batch 冒充 GitHub 资源已采集。

实现范围：

- `auth.rs`：只接受临时 `SecretValue`；拒绝空、非 UTF-8、空白/control/header-injection token；Authorization `HeaderValue` 标记 sensitive。
- `transport.rs`：reqwest `0.12.24` + rustls-only、15 秒 deadline、redirect disabled；固定 Accept、User-Agent 与 `X-GitHub-Api-Version: 2026-03-10`；4 MiB streaming body budget；仅暴露 allowlisted response headers。
- `client.rs`：固定 origin/path/query allowlist；20 页、100 items/page、200 requests/batch；同源 Link、重复/cycle 检测；ETag/typed 304；结构化 status/rate-limit 分类；fake clock；中途失败携带 completed pages。
- `descriptor.rs`：GitHub token auth、最小 `Metadata/Actions/Deployments: read` 权限、Full/Targeted modes、六类 planned resources 与五类 planned relations；全部 mapper coverage 保持 `Partial`。
- `error.rs`：统一向 `ConnectorFailure` 投影，错误与 Debug 不包含 token、body、URL、owner/repo 或 header value。

共享 wiring 只增加 workspace member/dependency pin、Cargo lock 与 dependency guard；内部生产依赖仅为 Core/API，公共 conformance 仅作为 dev dependency。

## 2. 自动化证据

聚焦测试共 15 项，覆盖：

- sensitive Authorization 和非 UTF-8/换行 token rejection；
- 固定请求 headers 与 ETag；
- 两页同源 pagination、跨 origin、多个 next、cycle/page budget；
- typed `304 NotModified`，不生成空 page；
- 第一页 fatal 与后续页 partial；
- 401、普通 403、rate-limit 403、429、404、5xx 分类；
- Retry-After 优先级、reset fake clock 和 1 小时 clamp；
- 4 MiB body limit、JSON failure 与 body sentinel redaction；
- Descriptor validation 和公共 conformance。

通过的验证：

```bash
rtk cargo test -p next-infra-connector-github
rtk cargo clippy -p next-infra-connector-github --all-targets -- -D warnings
rtk cargo test --workspace
rtk cargo clippy --workspace --all-targets -- -D warnings
rtk cargo fmt --all --check
rtk pnpm --dir apps/desktop run test:dependency-direction
rtk git diff --check
```

结果：crate 15 tests passed；workspace 204 tests passed、12 filtered；聚焦与 workspace strict Clippy passed；格式、diff whitespace 和 Cargo dependency boundaries passed。

## 3. Reader Review 处理

独立 `luna_worker` Reader Review 最初发现四个 blocker：403 rate-limit predicate、partial pagination 返回形状、retry delay 上限、first-party/third-party dependency 措辞。冻结文档已在实现验收前修订为唯一规则，并同时补齐 query allowlist、2,000 item budget、relation/module ownership、304 cache-miss、Link grammar、JSON/summary 边界和固定 User-Agent。

当前实现逐项对应修订后的合同：

- 403 仅在 `Retry-After` 存在或 remaining 精确为 `0` 时映射 RateLimited；
- `Result<GitHubFetch, GitHubPaginationFailure>` 明确保留 completed pages；
- Retry-After/reset clamp 为 `0..=3_600_000 ms`；
- dependency guard 分别校验 normal first-party closure 与 contract-test dev dependency。
