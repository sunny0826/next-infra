## 1. 交付结果

新增内部 `SourceSnapshot<T>`：

```rust
pub struct SourceSnapshot<T> {
    pub metadata: SnapshotMetadata,
    pub body: T,
}
```

所有 `QuerySource` method 现在通过一次调用同时返回 metadata 与 body。独立 `metadata()` method 已删除，`QueryService` 不再允许 Writer 合法插入 metadata/query 两次 source call 之间。

以下公开行为保持不变：

- QDTO schema 和 generated TypeScript。
- `niq1:` cursor 编解码。
- resource/change page limit。
- Topology depth/node/edge hard limits。
- not-found、source unavailable 和 contract error cleaning。
- Desktop Adapter 的 bounded command contract。
