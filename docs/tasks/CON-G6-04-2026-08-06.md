# CON-G6-04 Linux systemd Probe Parser 与 Mapper 验收记录

**日期：** 2026-08-06  
**状态：** `REVIEW / INTERNAL PASS`  
**冻结合同：** [`CON-G6-04-TASK-FREEZE-2026-08-06.md`](./CON-G6-04-TASK-FREEZE-2026-08-06.md)

实现位于 `crates/next-infra-connector-ssh/src/probes/linux.rs`。parser 只读取 UNIT/LOAD/ACTIVE/SUB 四个字段，description 完全丢弃；unit 必须属于 allowlist、以 `.service` 结尾并通过固定语法，state、rows、outputs 与 bytes 均有上限。

mapper 生成稳定 `ssh.systemd-service` 和 Host → Service provider relation；active/failed/transitional/other 分别映射 Healthy/Unhealthy/Degraded/Unknown。missing 不伪装 stopped/down，未支持 init system 不进入该 parser。
