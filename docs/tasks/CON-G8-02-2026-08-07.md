## Live smoke 暴露并修复的连接器问题（均已在本次验收前修复）

1. **认证方案错误**：连接器发送 `Authorization: Bearer`，v2 要求 `x-api-key: <token>`（官方文档确认）→ auth.rs + transport 修复。
2. **端点名错误**：v1 REST 路径（`/api/projects` 等）→ v2 RPC 风格：`project.all` / `server.all` / `deployment.all?applicationId=` / `domain.byApplicationId?applicationId=`；`application.all`、`domain.all` 在 v2 **不存在**（官方 OpenAPI 确认），应用改为从 `project.all` 嵌套结构派生。
3. **DTO 字段错误**：`id` → `projectId`/`applicationId`/`serverId`/`deploymentId`/`domainId` 驼峰；`domain` → `host`；`address` → `ipAddress`；`project_id`/`server_id`/`application_id` 改为从上下文/重命名注入；新增 `EnvironmentDto`。
4. **project.all 版本兼容**：新版实例用 `environments[]` 嵌套应用，旧版文档用顶层 `applications`——DTO 双形状容忍（serde default）。
5. **请求预算缺失**：新增 `MAX_APPLICATIONS_WALK=50` / `MAX_REQUESTS_PER_SYNC=200`，预算耗尽 → Partial + warning（对齐 github collector 纪律）；request_count 改为真实计数。
6. **transport 不允许查询串**：`resource()` 放行 `?`（仅路径允许，base URL 仍拒绝凭据/查询/片段）。
