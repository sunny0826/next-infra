# RHM-G3-05P1B Bounded Store Query Projection 验收记录

**日期：** 2026-08-03  
**状态：** `REVIEW`  
**范围：** `next-infra-store` DTO-neutral read projection；不依赖 Query QDTO、不实现 Runtime mapping 或 Tauri Composition。

## 1. 原子 snapshot

所有公开 query projection method 使用一个 SQLite read transaction，同时读取：

- `ProjectionMetadata` committed revision/time；
- 对应 resource/relation/change/sync/health body。

metadata 与 body 不再可能被 Writer 插入中间。读取失败时 transaction 回滚，不产生 revision。

## 2. Bounded projection API

### Resource search

- 稳定按 `resource_id` 排序。
- 支持 opaque inner `after` key 与 `limit + 1` 截断检测。
- Store hard limit 为 512；Query Service 仍保留公开 100 上限。
- 支持 name/display name/kind/external ID/resource ID 搜索。
- 支持 kind、connector type、Resource Health、Freshness 和 label filters。
- Freshness 使用 Runtime 传入的每 Connection cutoffs；缺失、倒置 cutoffs 直接失败，不猜默认值。
- 返回 `ProjectedResource`，包含 Core Resource、ConnectorType 与已分类 Freshness。

### Resource Detail

- 返回 normalized Resource、相关 Relations 与 Resource/Relation Changes。
- Relations 固定最多 400，Changes 固定最多 100。
- 独立返回 `relations_truncated` 与 `recent_changes_truncated`，Runtime 不得静默丢弃截断事实。

### Topology primitives

- bounded resource-ID lookup。
- bounded incoming/outgoing Relation page，稳定按 `relation_id` 排序并返回 inner cursor。
- Runtime P2 负责 depth traversal、node/edge hard limits、frontier 与 truncated；Store 不返回 QDTO。

### Changes、Sync 与 Health

- Recent Changes 按 `observed_at DESC, change_id DESC`，使用 composite inner cursor。
- resource filter 同时覆盖 Resource change 和端点相关 Relation change。
- kind filter 匹配 Resource/Relation persisted kind。
- Sync Status 返回 safe Connection projection 与 bounded recent runs。
- Health projection 聚合 Resource Health、Connector Health 与基于 cutoffs 的 Freshness。
- Connection list 返回专用 `ProjectedConnection`；类型中不存在 config 或 SecretRef 字段。

## 3. 安全与依赖边界

- Store crate 继续只依赖 Core。
- 不返回 QDTO、不编码 `niq1:`、不生成用户错误文案。
- Query projection 不暴露 Connection config、SecretRef、Secret value 或 raw Provider payload。
- SQL/DB path 错误仍只存在 Store internal error；Runtime/Query Service 必须继续清洗。
