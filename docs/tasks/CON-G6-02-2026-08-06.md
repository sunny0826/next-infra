# CON-G6-02 通用 Host Probe Parser 与 Mapper 验收记录

**日期：** 2026-08-06  
**状态：** `REVIEW / INTERNAL PASS`  
**冻结合同：** [`CON-G6-02-TASK-FREEZE-2026-08-06.md`](./CON-G6-02-TASK-FREEZE-2026-08-06.md)

实现位于 `crates/next-infra-connector-ssh/src/probes/common.rs`。identity、uptime、POSIX `df -Pk` 与 process state parser 均执行 UTF-8、字节、行数、字段、control 与 secret sentinel 边界；process command/name、raw uptime 和 load average 不进入 observation 或错误。

mapper 生成稳定 `ssh.host`、`ssh.filesystem`、`ssh.process-summary` 及两条 `ssh.contains`。identity failure fatal；uptime/filesystem/process failure 独立 partial。safe unknown uptime 保留 `unknown` bucket，但因 parser 成功，Host health 为 Healthy。

验收覆盖 Darwin/Linux、uptime 边界、df header/sort/overflow/cap、process cap/state 聚合、stable ID/relation、partial 和 redaction。SSH crate 与 workspace 回归见 [`GATE-G6`](./GATE-G6-2026-08-06.md)。未连接真实主机。
