# RHM-G3-05P0B Connection Snapshot Contract 验收记录

**日期：** 2026-08-03  
**状态：** `REVIEW`  
**范围：** Connection list 的 Query/QDTO/Desktop Adapter contract parity；不实现 Store→QDTO mapping 或 Tauri command registration。

## 1. 问题与修复

Goal 1 DesktopAdapter 遗留了 `getSnapshotMetadata`、`listResources`、`listRelations` 三个未被生产页面使用、没有 Rust Query Service 对应入口且缺少明确 bounds 的方法。保留它们会迫使 Composition 注册 stub 或绕过共享 Query Service。

本阶段：

- 删除三个未使用 legacy methods。
- 保留页面实际需要的 Connection list，并正式纳入 QuerySource/QueryService。
- 新增 `ConnectionSnapshotDto { metadata, items }`。
- Query Service 强制最多 200 Connections。
- Rust Desktop Adapter 增加 `list_connections` thin mapping。
- Real Adapter 只调用稳定 `query_list_connections` command。
- Overview/Connectors 消费 snapshot `.items`，不丢失权威 metadata contract。
- Empty Adapter 不再返回“成功但为空”的假 snapshot；Host 不可用时明确失败。

## 2. 生成与安全

- QDTO binding 数量由 39 增至 40，新增文件由 Rust `ts-rs` pipeline 生成，未手改。
- Connection DTO 只包含 ID、connector type、display name、enabled、health 与 success/attempt 时间。
- config、SecretRef、Secret value 与 raw Provider payload 不进入 QDTO。
