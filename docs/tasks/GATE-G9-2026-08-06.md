# GATE-G9: Provider 基础覆盖

Date: 2026-08-06
Status: INTERNAL-PASS / EXTERNAL-DEFERRED

## Evidence

- The four connector crates now have offline `ReadConnector` replay paths,
  fixed-origin request boundaries, allowlisted DTOs and descriptor catalog
  registration. Managed/self-hosted identities remain separate; self-hosted
  source failure preserves successful source observations as `partial`.
- Aliyun/Tencent descriptors now list ECS/CVM, VPC/subnet, security group,
  load balancer, public IP and DNS as individual modules. The desktop catalog
  consumes real descriptors rather than an empty snapshot.
- Aliyun RPC requests use sorted RFC 3986 canonical parameters and an
  HMAC-SHA1 signature. Tencent requests construct a TC3-HMAC-SHA256 signed
  POST payload. Both connectors have bounded per-module pagination, bounded
  retries for retryable rate limits with a capped `retry_after_ms`, and preserve partial
  coverage rather than fabricate deletion.
- Connector UI renders a Connector Coverage Matrix and keeps it distinct from
  connection health and Sync status.
