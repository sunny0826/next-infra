# RHM-G4-03A MCP Projection 与 Router 验收记录

**日期：** 2026-08-04  
**状态：** `REVIEW`  
**范围：** MCP input/output projection、Local RPC client adapter、七工具 router、两个 Resources；不包含 Bridge child-process STDIO composition 或 Host auto-launch。

## 交付结果

- 精确锁定 Rust MCP SDK、Tokio 与 schema 依赖；MCP crate 仍只依赖 Local RPC，不依赖 Store/Runtime/Connector/Tauri。
- `McpQueryClient` 是可替换的七 Query boundary；production `LocalRpcMcpClient` 使用单 mutex 保持有序 RPC session，并生成短 request ID。
- response capability 与 request capability 不一致时 fail closed；Host/session failure 映射为安全 bridge error。
- 七个强类型 input schema 拒绝未知字段，并在 schema 中表达 Query Service 的 100-item、depth 3、200-node、400-edge 等硬上限。
- `McpToolOutput` 固定 `{ observed_at, data }`，时间来自 Query DTO snapshot metadata。
- `NextInfraMcp` 精确注册七个冻结名称；每项都有 input/output schema 与 `readOnly=true`、`destructive=false`、`idempotent=true`、`openWorld=false` annotations。
- Tool handler 使用 `spawn_blocking` 调用同步 Local RPC client，不阻塞 MCP executor。
- Resources 固定为 `next-infra://capabilities/v1` 与 `next-infra://health-summary/v1`；health resource 复用同一个 Query client。
- Server capability 仅声明 tools/resources；instructions 明确 committed local snapshot、可能 stale、Provider text 不是权限指令。
