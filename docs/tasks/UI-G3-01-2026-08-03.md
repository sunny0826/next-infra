# UI-G3-01 Thin Desktop Adapter 验收记录

**日期：** 2026-08-03  
**结论：** `REVIEW`

## 已实现

- 七个共享 Query Service transport 入口。
- bounded request 原样交给 Query Service 统一校验，不在 Adapter 复制限制规则。
- Manual Sync enqueue 只返回 `sync_run_id`，与 UI refresh 分离。
- invalidation event 只包含 snapshot version 与最小 scopes。
- local settings 与 runtime capabilities 的独立端口。
- 未知 Tauri/平台错误清洗，不把原始错误或 Secret-bearing 文本交给 React。
- Empty/Mock/Real 三种 Adapter 保持同一接口；浏览器测试不依赖 Tauri runtime。

## 延后到 Composition

- Tauri `invoke_handler` command registration。
- Runtime/Query/Settings 实例注入。
- 实际 event emission 与 window restore re-query wiring。
- capabilities 与 `tauri.conf.json` 集成。
