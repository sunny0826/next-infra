## 1. 交付

在 `next-infra-connector-github::actions` 中新增：

- Workflow、Workflow Run、Job allowlisted serde DTO；未知 Provider 字段自动丢弃。
- 三类纯 mapper 与 `GitHubRepositoryContext`。
- `ActionMapperOutput`、逐 module complete/partial/bounded/failure 状态和稳定 merge/sort。
- Workflow 200、Run 100、Job 200/Run 的本地强制上限；repository 总 Job 2,000 上限常量供后续 collector 编排。
- numeric GitHub ID stable external ID，五类 Descriptor 中三类 Actions relation 的稳定 evidence。
- conservative health mapping，provider timestamps 仅作为属性，采集时间由调用方统一注入。

本任务不实现 HTTP collector、`ReadConnector`、Runtime/Store、UI/MCP 或 live API；不会把 bounded Actions 历史声明为 authoritative。

## 2. 安全与可视化字段

资源只保留首版可视化所需摘要。Run 不保留 SHA、actor、commit、PR、URL；Job 不反序列化 steps、runner name/group/labels；所有模块不接触 logs、artifacts、variables、environment 或 Secret。

名字、状态、branch 与 provider time 字符串限制为 1,024 bytes，control/private-key/Bearer sentinel 被拒绝。labels 仅包含低基数 `github.resource_type` 与 `github.status`，branch/event/name 不进入 labels。

## 3. 自动化证据

Actions 聚焦测试 8 项：

- rerun attempt 保持 Run external ID 与 evidence key；
- success/failure/cancelled/in-progress/未知 conclusion health；
- steps、runner、authorization 与 secret sentinel 未知字段不存活；
- 输入顺序不改变 resources/relations 输出；
- bounded/failure module 为 partial；
- mapper 强制 Run 数量上限；
- duplicate identity 与敏感文本拒绝；
- 三类资源/关系通过公共 conformance 与 Goal 2 Normalizer schema，secret sentinel count 为 0。
