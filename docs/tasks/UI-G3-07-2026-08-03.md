## 1. 交付结论

Shell 保持单写边界：feature 页面、generated QDTO、fixtures、Rust Adapter 与 Tauri Host 均未因本任务被修改。

## 2. 核实路径

- Global search 只执行有界本地 Resource 查询，选择结果进入 Inventory Detail 并打开 Resource Inspector。
- 从 Search 或 Inventory 选择的 Resource 会成为可达的 Topology focus；Topology 仍使用服务端冻结的 depth/node/edge 上限。
- Topology node 与 relation selection 进入统一 Inspector。
- Inspector 顺序为对象类型、身份、Current Facts、Evidence；relation 使用 DTO 中实际的 provider/configured/inferred provenance，不在 UI 猜测。
- Settings 关闭 Inspector；各 route 的 selection/detail/topology 状态按 Shell contract 隔离。
- `Command/Ctrl+K` 聚焦搜索，`Escape` 清空查询并关闭结果列表。
- Window focus 和 invalidation event 只增加 query version，使页面重新查询 Adapter；event payload 不作为权威状态。
- 异步 invalidation subscription 在组件提前卸载时会立即执行晚到的 unsubscribe，避免遗留监听器。
