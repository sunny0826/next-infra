# RHM-G3-05A Desktop Composition 验收记录

**日期：** 2026-08-04
**状态：** `REVIEW`
**范围：** 单实例 Desktop 的 AppState、Runtime/Query composition、12 个 Tauri commands、本地 settings 与 capability gate；不包含 05B native Host effects。

## 交付结果

- `SharedStore::open(path)` 内部只执行一次 `Store::open`；Runtime backend 与两个 QueryService façade 共享同一 `CommittedQuerySource`/SharedStore handle。
- Tauri setup 创建一次 AppState，启动 interactive Runtime，并注册已冻结的 12 个 command 名称。
- 八个 query commands 只调用 `DesktopQueryAdapter`/QueryService，不复制 SQL、cursor、bounds、Freshness 或 QDTO mapping。
- LocalSettings 使用 app data 目录中的原子 JSON replace；budget 最低 64 MB、retention 最低 1 天。
- `user_quit` 输入不可覆盖 Host latch；未接入的 start-at-login、Manual Sync 与 MCP auto-launch capability 均为 false。
- `runtime_manual_sync` 返回安全 `sync_unavailable`，不伪造 SyncRunId、不写 running run、不调用 Provider。
- Composition 错误不返回 SQL、DB path、Provider payload 或 Secret。
