# CON-G6-05 SSH ReadConnector、Partial 与 Replay 纵切验收记录

**日期：** 2026-08-06  
**状态：** `REVIEW / INTERNAL PASS`  
**冻结合同：** [`CON-G6-05-TASK-FREEZE-2026-08-06.md`](./CON-G6-05-TASK-FREEZE-2026-08-06.md)

`SshConnector` 先执行 identity，再按 Darwin/Linux 只选择一个 service probe；无 allowlist 时不读取 service list。Full complete 使用 `AuthoritativeFull`，child transport/parser failure 保留已成功 observation 并使用 Partial；top-level 或 in-band Host Key mismatch/cancel 均 fatal，丢弃 staged identity。

SQLite + Normalizer + SyncEngine replay 已证明：service probe partial 不累计 missing、不 tombstone；其后第一次 authoritative missing 保持 Active，第二次才 Tombstoned。Targeted 因现有 coverage 只能携带 normalization 后内部 ID，显式保持 Partial，不伪造 ResourceId。

公开注入边界只接受 `ProbeId` 与 bounded collected stdout，不接受 command、argv、path 或地址。生产 crate 仍不依赖 Store/Sync/Runtime/Tauri/MCP；replay 依赖仅为 dev dependency。
