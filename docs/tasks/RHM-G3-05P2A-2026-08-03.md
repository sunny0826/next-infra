# RHM-G3-05P2A SharedStore Ownership 验收记录

**日期：** 2026-08-03  
**状态：** `REVIEW`  
**范围：** Runtime 与 SyncEngine 的唯一 Store ownership；CommittedQuerySource/QDTO mapping 留 P2B。

## 1. 交付结果

- 新增 cloneable `SharedStore`，内部唯一持有 `Arc<Mutex<Store>>`。
- `SharedStore` 实现既有 Core `StoreReader` 与 `StoreWriter` ports。
- clone 只复制 handle，不 reopen SQLite、不创建第二 WriterQueue。
- `SqliteRuntimeBackend` 改为 `SyncEngine<SharedStore>`。
- Composition 可先创建一个 SharedStore，再分别传给 Runtime backend 与后续 CommittedQuerySource。
- recovery、WriterQueue commit/drain 与 WAL checkpoint 全部通过同一个 Store mutex。
- poisoned lock 映射为 Store internal contract error，后续仍由 Query/Adapter 清洗。

## 2. 行为证据

现有真实 SQLite Runtime integration 改为：

1. 创建一次 `Store::open`。
2. 包装为 SharedStore。
3. Runtime 使用 SharedStore clone 执行 startup interrupted recovery。
4. 测试通过原始 SharedStore clone 观察 recovered SyncRun。
5. WriterQueue enqueue/stop drain/checkpoint。
6. 同一 SharedStore clone 观察最终 succeeded SyncRun。

这证明 QuerySource 后续可共享相同 handle，而不是依赖 Runtime 内部借用或第二 connection。
