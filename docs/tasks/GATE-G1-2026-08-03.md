## 3. 验证结果

以下冻结合同与 Gate 补充命令全部以退出码 0 完成：

```bash
rtk cargo metadata --locked --format-version 1
rtk cargo fmt --all --check
rtk cargo test -p next-infra-core --locked
rtk cargo test -p next-infra-query --features typescript-bindings --test export_types --locked
rtk git diff --exit-code -- apps/desktop/src/generated/query
rtk cargo test --workspace --all-targets --locked
rtk cargo clippy --workspace --all-targets --locked -- -D warnings
rtk pnpm --dir apps/desktop install --frozen-lockfile
rtk pnpm --dir apps/desktop lint
rtk pnpm --dir apps/desktop test
rtk pnpm --dir apps/desktop test:query-bindings
rtk pnpm --dir apps/desktop build
rtk cargo build -p next-infra-mcp-bridge --bin next-infra-mcp --locked
rtk pnpm --dir apps/desktop tauri build
rtk pnpm --dir apps/desktop test:bundle-boundary
rtk pnpm --dir apps/desktop test:desktop-smoke
```

关键结果：

- workspace tests：5 项通过，16 个 test targets 无失败；Clippy 无 warning。
- Desktop tests：5 个测试文件、30 项测试全部通过。
- Query binding：导出测试通过，受版本控制的生成物无漂移。
- release bundle：`target/release/bundle/macos/Next Infra.app` 构建成功。
- bundle 内只有 Desktop 主 executable；`Contents/MacOS` 与 `Contents/Resources` 均不存在 `next-infra-mcp`。
- manifest/source 扫描未发现 Provider SDK 或真实凭据；唯一 secret/credential/token/password 命中来自 QDTO 负向契约测试。
