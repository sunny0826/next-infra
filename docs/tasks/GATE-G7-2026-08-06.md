# GATE-G7 Binding / Topology / Timeline 验收门

**日期：** 2026-08-06  
**内部状态：** `PASS`

## 内部证据

- Binding Service 支持 create、update、disable 和 reconcile；缺失 endpoint 会保留 configured relation，并标记 Binding 为 `unresolved`、Relation 为 `orphaned`。
- Inference 使用确定性的 relation/evidence identity 和输入版本 provenance；provider、configured、inferred 三类 evidence 以独立记录、投影和 UI 线型呈现。
- SQLite schema v3 保存 Binding、InferenceRun 和推断输出；Binding/Inference 提交的成功及回滚路径都有原子性测试。
- Topology 默认 depth 1，查询默认 100 nodes / 200 edges，服务端 hard limit 为 200 / 400；frontier、unresolved label 与有界相邻节点键盘导航已覆盖。
- Binding UI 只能调用 Desktop Adapter 的专用本地命令；可以新建、选中 configured evidence 后更新或 disable，再获取同一个有界 topology。
- Timeline 按 SyncRun / Binding / Inference origin 分组，提供版本链接与显式分页；Store-backed integration test 验证分页无重叠、inference provenance，以及 limit 0 与大于 200 被拒绝。
- 2026-08-06 验证：`rtk cargo test --workspace`（292 passed，12 filtered）；`rtk cargo test -p next-infra-desktop-adapter`（37 passed）；`rtk npm test`（18 files / 79 tests）；`rtk npm run lint` 与 `rtk npm run build` 已通过。

## 边界

- 没有自动资源合并、按时间邻近推断因果、无界 topology 查询或无限 Timeline。
- 不执行 MCP、真实 SSH、Apple identity / codesign / notarization 测试；这些是用户明确延后的外部项目，与 G7 的本地合成验收无关。
