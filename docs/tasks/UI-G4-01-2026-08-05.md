# UI-G4-01 Host/MCP State UI 验收记录

**日期：** 2026-08-05  
**状态：** `REVIEW`

## 交付结果

- Settings 将 start-at-login 与 MCP auto-launch 明确分离。
- `LocalSettings.user_quit` 不再信任 settings JSON 中的旧值；每次 command 都读取共享 owner-only marker contract。
- Runtime capabilities 根据当前 stable App、strict IntegrationRecord、`allow_mcp_auto_launch` 与 marker 状态实时计算。
- MCP auto-launch 只读显示 `available` / `unavailable`，同时显示具体原因；UI 不提供修改 IntegrationRecord 或绕过签名授权的入口。
- user Quit 只读显示 `clear` / `latched`。latched 时明确提示只能通过 interactive launch 或已启用的下一次 login launch 清除。
- 页面没有 Agent/MCP/user command 可直接清除 suppression；settings update 继续保留 Host-owned latch。
- `host_unavailable` 不被渲染为资源 empty；Settings 使用独立 Host/MCP capability 状态说明安装、授权或 suppression 问题。

## 验收证据

- Rust composition tests 覆盖 missing integration 与 explicit Quit reason。
- React tests 覆盖 start-at-login/MCP 分离、unavailable reason、clear/latched 状态、恢复指引及无 clear button。
- Desktop TypeScript lint、Vitest、production build 与 dependency direction 均通过。

## 安全边界

本任务只读取本地 Host integration 状态，不展示 Secret/SecretRef，不写 Provider，不生成 IntegrationRecord，也不改变 Codex/Hermes 配置。
